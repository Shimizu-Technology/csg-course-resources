# JavaScript Fundamentals · learner starter

**Course status:** preparation draft. No enrollment or date is announced here. No previous programming language is required.

Create a Hafa Code JavaScript project or run Node.js locally. Copy [tracker-starter.js](starter/tracker-starter.js). Complete its six `TODO` functions to total six fictional expenses, group them by category, find the largest item, compare the total to a budget, and print a report. The starting records total 118; Food is 61, Transport 48, Supplies 9, and the budget is 120. Check an empty list, a missing category, and an exact-budget case.

The full lessons and twelve exercises belong in CSG Learn. Paste the exact final source and test output there. A project link may accompany the saved code.
