# Code School of Guam course resources

This repository holds small, copyable code examples and starter files for Code School of Guam courses. **CSG Learn is the course home:** use it for lessons, due dates, submissions, feedback, and questions. [Hafa Code](https://code.shimizu-technology.com/) lets you run the Python examples in a browser without installing anything.

## Courses

| Course | Status | Start here |
| --- | --- | --- |
| Python Fundamentals, December 2026 pilot | Prepared for invited learners; course opens in Learn | [Course resources](python-fundamentals/2026-12/README.md) |

The Python course runs December 1–20, 2026. It has three weeks of short lessons and practice, plus one private hour each week for each enrolled learner. Your instructor will give you access to the course in Learn. A GitHub account and local Python installation are optional.

## How to use these files

1. Open the matching lesson in CSG Learn first. The lesson tells you what to build and where to submit it.
2. Copy a starter into a fresh Hafa Code Python project or your own local folder.
3. Change and test your code. Paste the version you want reviewed into the Learn exercise. You can add a GitHub or Hafa Code link as a second reference.

A link alone is not the reviewed snapshot: repository branches and shared Hafa projects can change. Keep the code itself in Learn when you submit.

## For course staff

Keep learner files here free of answers, private meeting links, student work, personal information, tokens, and client data. Staff solutions and assessment notes belong in the staff-only CSG Learn fields and the private Brain Dump pilot assets. Before a cohort starts, compare the starter and examples here with the current Learn lesson, run them in the production Hafa Python runtime, then make the repository available to the cohort. See [release checks](RELEASE.md).

This repository is private during pilot preparation. Do not describe it as a public download until its access has been deliberately changed and checked.
