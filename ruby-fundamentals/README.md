# Ruby Fundamentals · learner starter

**Course status:** preparation draft. No enrollment or date is announced here. No previous programming language is required.

Create a Hafa Code Ruby project or use local Ruby. Copy [study_report_starter.rb](starter/study_report_starter.rb) and run it before editing. The starter has five `TODO` functions. Build a study-session report that totals minutes, groups minutes by topic, finds the longest session, compares the total to the goal, and produces a readable summary. The six fictional sessions total 135 minutes, and the goal is 120. Check an empty list, an exact-goal case, and a repeated topic.

The full lessons and twelve exercises belong in CSG Learn. Paste the final Ruby source, output, and explanation there. A Hafa or GitHub link is an optional second reference.
