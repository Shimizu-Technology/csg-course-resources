## First run

Open a new Python project in Hafa Code and paste [hello.py](starter/hello.py). Run it, change one word, and run it again. Paste the changed line and output into the Learn orientation exercise.

## Final project

Start with [expense_summary.py](starter/expense_summary.py). It contains six example expenses and a budget of 120 whole dollars. Fill in the `TODO` functions and test the cases in the [checklist](practice/project-checklist.md). The whole-dollar amounts are for learning Python; this project is not accounting software.

If you work locally, keep your own copy in a folder or repository. You may add that link to your Learn submission, but paste the code and output there too. Do not include actual bank, client, or family financial data.
