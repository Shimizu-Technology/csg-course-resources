# Frontend with JavaScript · learner starter

**Course status:** preparation draft. JavaScript Fundamentals or equivalent functions, arrays, objects, and events are recommended.

Start a Hafa Code Web project or a local folder with these three files: [index.html](starter/index.html), [styles.css](starter/styles.css), and [app.js](starter/app.js). The initial page has semantic headings, a labeled task form, and a task area; its behavior and responsive layout are intentionally unfinished. Your final Study Plan should add and complete tasks, filter them, show a remaining count and clear empty states, preserve keyboard access, and use safe text rendering. Test at a narrow and a wide viewport.

The full lesson instructions, twelve exercises, and project submission belong in CSG Learn. Paste the final three files or submit the complete project artifact as directed there, plus test results and screenshots. A Hafa share or repository link is an optional second reference; do not rely on a link as the only reviewed copy.
