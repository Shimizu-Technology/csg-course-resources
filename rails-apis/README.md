# APIs with Ruby on Rails · learner starter

**Course status:** preparation draft. Ruby Fundamentals or equivalent Ruby skills and basic HTTP are recommended. This course requires a local Mac or Windows/WSL development environment; it has not completed a fresh setup rehearsal.

Use the [Practice Sessions API starter](study_api_starter/README.md) in its own folder. It is a local Rails 8.1 project with intentionally unfinished controller actions and model validation. Follow its setup steps, confirm that `GET /api/v1/practice_sessions` returns `200` and `[]`, then implement and test creating, reading, updating, deleting, and rejecting invalid practice sessions. Do not deploy this training app or use real student data.

The full lessons, exercises, request examples, and final rubric belong in CSG Learn. Submit the source, request-test results, and a short explanation there. A repository link may accompany your saved evidence.
